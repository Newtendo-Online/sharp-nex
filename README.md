## Why C# (.NET 10)?

* 🚀 **High Performance:** Near C++ speed using modern .NET 10 optimizations.
* 🛡️ **Memory Safe:** Protects against crashes and vulnerabilities when processing raw, untrusted UDP datagrams.
* ⚡ **Clean & Maintainable:** Much faster to write, structure, and scale than legacy C++ codebases.
